Parti-Scouts Wie weit gehst du?

WIE WEIT
GEHST DU?

8 Situationen, eine nach der anderen. Keine Vorlesung, keine vorgegebene richtige Antwort — nur deine Wahl. Am Ende siehst du, wie deine Entscheidungen im Vergleich zur Gruppe aussehen.

Allein spielen

Spiel die ganze Geschichte für dich allein durch, in deinem eigenen Tempo.

Mit einer Gruppe spielen

Ein Teamer leitet eine gemeinsame Runde. Alle beantworten dieselben 8 Situationen — am Ende seht ihr, wer wie entschieden hat. Gib den Code ein, den ihr im Raum bekommen habt.

Als Teamer eine Runde starten

Erstellt eine Session für eure Gruppe. Ihr bekommt einen Code für die Teilnehmenden und einen gemeinsamen Bildschirm für den Raum.

Das Spiel enthält Themen wie Konflikt, Gruppendruck und Gewalt. Es ist Teil der Parti-Scouts-Präventionsarbeit und für die Nutzung mit Begleitung durch einen Teamer gedacht.
